Morphy's Opera Game

Paris, 1858. Paul Morphy dismantles two consulting opponents in seventeen moves at the Paris Opera House — still one of the most famous miniatures ever played. Watch it unfold with commentary and arrows, and when the board lights up blue, it's your move.

How to play

Two puzzle moments are built into the game above.

  • Press play, or click the board, to start the game.
  • Twice, the board pauses and gets a blue outline — that's a puzzle. One is a single move, the other a two-move mating sequence.
  • Drag the piece you think Morphy played.
  • Wrong guess? The move snaps back with a shake — try again, there's no limit.
  • Solve it and the game resumes automatically, right where it left off.

Built with a single <pgn-player> element and two inline PGN comment markers: [P] for a one-move puzzle, [P3] for a three-ply sequence. No extra markup, no second board — see the README for the full syntax.
